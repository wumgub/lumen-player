# Keyboard shortcuts

## Anywhere

These don't fire while you're typing in a text box.

| Key | Does |
|---|---|
| **Space** | Play / pause |
| **⌘ →** (macOS) / **Ctrl →** (Windows, Linux) | Next song |
| **⌘ ←** (macOS) / **Ctrl ←** (Windows, Linux) | Previous song / restart the current one |
| **f** | Fill the window with the music video if one is showing, otherwise toggle the immersive visualizer |
| **Esc** | Leave immersive mode or the full-window video |
| Media keys **⏯ ⏮ ⏭** | Play/pause, previous, next, even while Lumen is in the background |

## In dialogs and menus

| Where | Key | Does |
|---|---|---|
| Rename boxes, new playlist | **Enter** / **Esc** | Save / cancel |
| Add to album | **Enter** | Add to the album name you typed (creates it if it's new) |
| Note | **⌘ Enter** / **Ctrl Enter** | Save (plain Enter starts a new line) |
| Any dialog | **Esc** | Close it |
| Song menu | **Esc** | Close it |
| Search box | **Esc** | Clear the search and close the box |

## Mouse

| Action | Does |
|---|---|
| Click a song | Play it, queuing up the rest of that list |
| Right-click a song | Song menu |
| Double-click the video | Fill the window / go back |
| Drag a playlist in the sidebar | Reorder playlists |
| Drag a song (album, in Edit mode) | Reorder the album |
